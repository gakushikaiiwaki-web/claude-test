# claude-test

Claude Code（クラウド版）と GitHub の連携を試すためのリポジトリです。

## 概要

- Claude Code から GitHub リポジトリを操作できるかを確認するためのテスト用リポジトリ
- Claude Code は作業ごとのブランチ（例: `claude/...`）に変更をコミット・プッシュします

## 使い方

1. [claude.ai/code](https://claude.ai/code) を開き、このリポジトリを選んでセッションを始める
2. やりたいことを日本語で依頼する（例：「スクリプトを作って」「README を更新して」）
3. Claude Code が作業用ブランチに変更をコミット・プッシュする
4. GitHub 上で変更を確認し、必要ならプルリクエストを作って `main` にマージする
